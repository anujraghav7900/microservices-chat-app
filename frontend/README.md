# 🚀 Microservices Chat Application

A modern microservices-based real-time chat application developed using Docker, CI/CD pipelines, and containerized architecture.

---

# 📌 Project Overview

This project demonstrates the implementation of a scalable microservices architecture using multiple independent services communicating through Docker networking.

The application includes:
- Frontend Service
- Backend/API Service
- Authentication Service
- Database Service

The project also demonstrates:
- Docker Compose orchestration
- Maven build automation concepts
- GitHub Actions CI pipeline
- Jenkins CI/CD automation

---

# 🏗️ System Architecture

```text
Frontend Service
        ↓
Backend/API Service
        ↓
Database Service
```

Additional services:
- Authentication Service
- Docker Network Communication

# 🐳 Docker Compose Setup

## Run Complete Application

```bash

```

## Stop Containers

```bash
docker-compose down
```
